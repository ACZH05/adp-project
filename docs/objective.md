The objective of this project is to develop an entertainment license application system based on artificial intelligence (AI) technology that can assist in the document verification process and application processing in a more efficient manner.

1. To develop an online entertainment license application platform equipped with an automatic document verification function using AI technology, before the application is forwarded to an officer for processing.

2. To reduce cases of incomplete applications by at least 60% through an automated preliminary document screening system.

3. To reduce the processing time for entertainment license applications from a manual process to a faster and more efficient digital system within six months following implementation.
